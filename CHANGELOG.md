# Changelog

## [Unreleased]

### Added

- A playable Age of Legends tracker with three Menhirs that track free-text locations and markers, plus an Enemy Army section for free-text locations and units.

## [1.1.0] - 2026-11-01

### Added

- Character-specific display colors on character nameplates.
- A footer crediting Awaken Realms for *Tainted Grail* images and artwork, with a link to the publisher's website.

### Changed

- Moved the character delete control to the top-right of each character card and replaced the bin icon with a circled X.

## [1.0.1] - 2026-10-30

### Changed

- Changed the application source license from the Unlicense to the MIT License.

## [1.0.0] - 2026-10-30

The first release of the Tainted Grail Save Sheet Tracker is now available.

### Added

- A responsive digital save sheet for the **Fall of Avalon** campaign.
- Campaign, chapter, and day tracking, plus Menhir dials, quest dials, and Guardian locations.
- Up to four character sheets with player names, stats, resources, and attributes.
- 71 campaign statuses, with box counts, numbered or unnumbered progress, and reference captions checked against the campaign save sheet.
- 16 removed-location rows and campaign notes.
- Automatic browser storage for campaign progress, along with named saves that can be restored or deleted.
- Offline JSON backup and restore for all site local storage, with file validation and a clear replacement warning.
- An English interface powered by i18next.
- Responsive layouts for desktop, tablet, and mobile.
- Campaign selector entries for Last Knight, Age of Legends, Red Death, and Kings of Ruin, marked as coming soon.
